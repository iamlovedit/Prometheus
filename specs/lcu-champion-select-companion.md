# LCU 英雄选择伴随窗口

## 目标

当英雄联盟客户端进入英雄选择阶段时，Prometheus 隐藏完整主窗口，并在
`LeagueClientUx` 主窗口边缘显示一个紧凑的伴随窗口。伴随窗口必须展示当前可获取的
队友战绩，并根据队列类型展示相应的英雄自动化信息。

该功能是独立 WPF 窗口与公开 LCU API 的组合，不向英雄联盟客户端或游戏进程注入代码，
不读取屏幕图像，也不修改 LCU 窗口内容。

## 生命周期

0. “实用工具”与托盘“游戏辅助”菜单中的“选人阶段吸附窗”开关共享状态，默认开启并
   持久化。关闭时立即隐藏伴随窗口，后续英雄选择阶段不再自动显示，也不得隐藏
   Prometheus 主窗口；重新开启后，若当前仍在 `ChampSelect` 且 LCU 窗口可用，则立即
   恢复伴随窗口。
1. `GameflowPhase` 首次进入 `ChampSelect`，且可定位到可见的 LCU 主窗口时：
   - 创建或复用伴随窗口；
   - 将伴随窗口定位到 LCU 边缘；
   - 成功显示伴随窗口后隐藏 Prometheus 主窗口。
   无论伴随窗口是否启用，Prometheus 主窗口的内容区都应在首次进入 `ChampSelect` 时导航到
   比赛信息页；同一英雄选择阶段内的后续快照不得重复强制导航。
2. 同一英雄选择阶段内，用户从托盘手动重新打开 Prometheus 后，不重复强制隐藏主窗口。
3. 离开 `ChampSelect`、LCU 断开、LCU 关闭或 LCU 最小化时，隐藏伴随窗口。
4. LCU 从最小化恢复且仍处于 `ChampSelect` 时，重新显示伴随窗口。
5. 离开英雄选择阶段后不强制弹出 Prometheus 主窗口，应用继续驻留托盘。
6. 应用退出时停止窗口跟踪、解除事件订阅并关闭伴随窗口。

## 窗口吸附

- 伴随窗口默认贴在 LCU 右侧外缘；右侧工作区空间不足时改贴左侧。
- 两侧均不足时，窗口贴在 LCU 内部右缘，并限制在当前显示器工作区内。
- 伴随窗口随 LCU 移动、调整大小、跨显示器和 DPI 变化而重新定位。
- LCU 位置或可见状态变化后，伴随窗口应在 500 毫秒内完成同步。
- 伴随窗口无标题栏、不显示任务栏按钮、不抢占 LCU 的键盘焦点。
- 伴随窗口不得使用全局置顶；LCU 被激活时可以把伴随窗口提升到 LCU 之上。
- 伴随窗口在普通非置顶 Z 层中保持位于 LCU 正上方；即使 LCU 当前不是前台窗口，
  `InsideRight` 覆盖模式也不得被 LCU 自身遮挡。

## 展示内容

### 队友战绩

- 使用 `IMatchService.Current.Roster.MyTeam`，排除本地玩家，最多展示四名队友。
- 每名队友展示当前可用的英雄头像、Riot ID、单排段位、最近 20 场胜负/胜率和平均 KDA。
- 加载过程中展示加载状态；LCU 隐藏玩家身份或接口不返回数据时必须如实展示不可用状态，
  不得伪造战绩。
- 阵容与战绩随 `SnapshotChanged` 实时更新。

### 大乱斗与海克斯大乱斗

- 队列 `450` 显示为极地大乱斗，队列 `2400` 显示为海克斯大乱斗。
- 展示本地玩家当前英雄。
- 自动交换开启时，展示当前优先级列表中可从备战席换取的最高优先级英雄；若当前英雄已经
  位于偏好列表中，则当前英雄即为自动化结果。
- 自动交换关闭、没有候选或备战席不可用时，展示明确状态。

### 排位与匹配

- 队列 `420`、`440` 分别显示单双排和灵活排位；其他非大乱斗英雄选择显示为匹配模式。
- 分别展示自动 Ban 和自动 Pick 的开关状态、目标英雄与当前执行状态。
- 当本地玩家对应操作已带有英雄 ID 时，以实际操作英雄为准；否则展示配置中优先级最高的
  候选英雄。
- 没有配置候选或自动化关闭时展示明确状态。

## 容错

- 找不到 LCU 窗口时保留 Prometheus 主窗口，不显示悬空伴随窗口。
- 原生窗口 API 调用失败不得中断 LCU 数据协调器或导致应用退出。
- 英雄名称或图标加载失败时保留英雄 ID/占位状态，其他队友数据继续显示。

## 验收标准

- 进入和离开 `ChampSelect` 能正确控制两个窗口的可见状态。
- 首次进入 `ChampSelect` 时自动导航到比赛信息页，同阶段后续快照不重复导航。
- 实用工具与托盘开关双向同步；关闭后伴随窗口立即隐藏且不再自动弹出，开关状态可跨
  应用启动保持。
- LCU 移动、最小化、恢复和跨显示器时伴随窗口行为符合“窗口吸附”规则。
- 大乱斗、海克斯大乱斗、单双排、灵活排位和普通匹配的展示分支正确。
- 队友列表不包含本地玩家，且不超过四人。
- 自动交换、自动 Ban、自动 Pick 的关闭、未配置、等待、执行和完成状态可区分。
- 窗口定位与模式/目标选择逻辑有自动化测试。
- `en-US.xaml` 与 `zh-CN.xaml` 的新增资源保持一致。
