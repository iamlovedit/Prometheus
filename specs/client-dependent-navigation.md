# LCU 依赖页面导航

> 适用范围：主窗口侧栏、Shell 事件导航，以及 LCU 连接状态变化时的页面生命周期。

## 1. 页面分类

1. 主页和设置不依赖当前 LCU 连接，始终允许进入。
2. 生涯、藏品、战绩查询、对局信息和实用工具依赖 LCU；只有
   `IMatchService.Current.ConnectionState == Connected` 时允许进入。
3. 实用工具需要从 LCU 加载英雄与自动化配置所需的数据；未连接时不得进入，即使其中部分开关
   由本地设置持久化。

## 2. 导航与连接状态

1. LCU 未连接时，受限侧栏项必须禁用，并提供本地化的客户端启动提示和可识别的锁定状态。
2. 连接进入 `Connected` 后，受限侧栏项立即恢复可用。
3. `Connecting` 或 `Reconnecting` 时不得新进入受限页面；若用户已在受限页面，保留当前页面，
   不因短暂重连强制跳转。
4. 用户停留在受限页面时，连接进入 `Disconnected` 或 `Error`，Shell 必须导航回主页。
5. 菜单命令、托盘入口、事件聚合器和自动导航必须共用同一导航守卫，不得绕过连接前置条件。
6. 被拒绝的导航不得加载目标模块、修改当前菜单选中状态或更新窗口标题。

## 3. 验收标准

1. [ ] 应用离线启动时，只有主页和设置可用，另外五个页面不可用。
2. [ ] LCU 连接成功后，五个受限页面立即可用。
3. [ ] 连接中或重连中不能新进入受限页面，已打开页面保持不变。
4. [ ] 已打开受限页面后断开或连接错误会返回主页。
5. [ ] 事件导航在离线时不能加载或打开受限页面。
6. [ ] 侧栏锁定提示保持中英文资源一致。
7. [ ] 命令可用状态、事件守卫、重连保留和断开回主页具有自动化测试。
